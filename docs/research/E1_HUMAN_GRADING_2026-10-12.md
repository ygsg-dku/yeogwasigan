# E1. 사람 채점 (2026-10-12)

E1(2026-10-05, 게이트웨이를 거친 실제 AI 전송)의 AI 답 4건을 사람이 직접 읽고 채점했다. 채점자는 소희 1명이다. E1 문서의 ✓/△는 Claude의 예비 판단이었고, 이 문서가 그것을 사람이 다시 확인한 기록이다.

## 방법

- 입력: E1 AI 응답 원본 (`results/e1_gateway_live_20261005/*.decided.json`의 `answer`, git 제외). 모두 `mode: live`, `gpt-5.1-2025-11-13`
- 기준: 정답은 심은 장애(`scoring/scenarios.json`의 설명). 서비스를 맞혔는가, 원인을 맞혔는가 두 가지를 본다
- 판정: ✓ 둘 다 맞음 / △ 하나만 맞거나 구체적이지 않음 / ✗ 둘 다 틀림
- 키워드 일치가 아니라 답의 의미로 판정했다

사람 판정과 Claude 예비 판정이 4건 모두 같다.

## 메모

- 키워드 검사로는 S3이 서비스·원인 모두 통과하지만, 읽어 보면 DB 잠김을 못 짚었다. 시험에서 AI의 정확도를 잴 때는 키워드 일치만으로 과대평가될 수 있어, 사람이 의미를 보고 채점해야 한다. (실전에서는 채점하지 않고, 사람이 AI의 답을 단서로 삼아 직접 확인한다)
- S1 답에 로그 본문(body) 속 이메일·카드번호 값이 그대로 인용됐다(시험용 가짜 값). 칸 단위 담기로는 본문 속 값을 막지 못한다는 E1의 한계가 답에서도 확인됐다
